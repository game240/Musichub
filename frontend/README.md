# Music Hub Frontend

Web client for Music Hub, a personal cloud music locker and streaming service.

## Tech Stack
- React 19 + TypeScript
- Vite + Tailwind CSS
- TanStack Query v5 + Zustand
- Native HTML5 Audio with HTTP Range Presigned URL streaming
- ESLint + Prettier

## Design & Language System
- **UI Aesthetic**: Linear-inspired dark interface with deep charcoal `#08090a`, subtle 1px border lines, frosted acrylic glass, and signature `#5e6ad2` violet accents.
- **Typography**: Pretendard Variable with tabular figures (`tnum`) for jitter-free numbers (seek time, byte sizes).
- **Default Language**: Korean (`ko-KR`).

## Commands
```bash
# Start development server
pnpm dev

# Type check and build for production
pnpm build

# Run ESLint check
pnpm lint

# Format code with Prettier
pnpm format

# Check formatting
pnpm format:check
```
