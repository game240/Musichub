# Music Hub Frontend

Web client for Music Hub, a personal cloud music locker and streaming service using Cloudflare R2.

## Tech Stack
- React 19 + TypeScript
- Vite + Tailwind CSS
- TanStack Query v5 + Zustand
- Native HTML5 Audio with HTTP Range Presigned URL streaming
- ESLint + Prettier

## Commands
```bash
# Start development server
pnpm dev

# Type check and build for production
pnpm build

# Run ESLint check
pnpm lint

# Format code with Prettier
pnpm format

# Check formatting
pnpm format:check
```
