## 1. Execution Strategy & Rules

1. **Rule Compliance**:
   - `AGENTS.md`: "Design approved before implementation; plan written before touching code".
   - Commit format: `type: subject` (e.g. `feat: add db migration for indexes and lyrics`).
   - PostgreSQL 16 & Flyway migration conventions.
2. **Backward Compatibility**:
   - Schema modifications use additive DDL (`ADD COLUMN ... DEFAULT ...`) to prevent breaking existing data.
   - Non-blocking index creation strategy (`IF EXISTS` checks).

---

## 2. Step-by-Step Milestones

### Milestone 1: Flyway V2 Migration Creation
- [ ] Create `backend/src/main/resources/db/migration/V2__optimize_indexes_and_metadata.sql`:
  - Drop obsolete single-column indexes: `idx_music_file_user_id`, `idx_music_file_status`.
  - Add composite index: `idx_music_file_user_status_created ON music_file(user_id, status, created_at DESC)`.
  - Add index-only scan index: `idx_music_file_user_size ON music_file(user_id, file_size)`.
  - Add columns: `lyrics TEXT`, `play_count INT NOT NULL DEFAULT 0`, `last_played_at TIMESTAMPTZ`.

### Milestone 2: Backend Domain Entity Updates
- [ ] Update `MusicFile.kt`:
  - Add `DELETED` to `MusicFileStatus` enum.
  - Add properties `lyrics`, `playCount`, `lastPlayedAt`.
  - Update `updateMetadata` method to accept and assign `lyrics`.
  - Add helper methods `incrementPlayCount()` and `markDeleted()`.

### Milestone 3: Metadata Extraction Extension (Lyrics)
- [ ] Update `AudioMetadata.kt`:
  - Add `val lyrics: String? = null`.
- [ ] Update `JaudiotaggerMetadataReader.kt`:
  - Extract `tag.getFirst(FieldKey.LYRICS)` and populate `AudioMetadata.lyrics`.

### Milestone 4: Service & DTO Updates
- [ ] Update `MusicFileController.kt` (or DTO definition):
  - Add `lyrics`, `playCount`, `lastPlayedAt` to `MusicFileDto`.
- [ ] Update `MusicFileService.kt`:
  - Map `metadata.lyrics` to `musicFile.lyrics` during upload completion.
  - Implement soft delete / safe cleanup in `deleteMusicFile`.

### Milestone 5: Verification & Compilation
- [ ] Run `./gradlew test` or `./gradlew compileKotlin` to verify type safety and entity mapping.
- [ ] Verify Flyway migration script formatting and JPA `@Table`/`@Column` annotations match V2 DDL.
